# Nour Abotaleb Hassan — Portfolio

A bilingual English/Arabic portfolio for Flutter development and UI/UX design.

**Live site:** https://nour-abotaleb-hassan.github.io

The site presents eight projects, with GitHub links for the Flutter apps and case-study links for Mahsool. It includes responsive layouts, an Arabic/English switch, and category filters. Project preview images are stored in `assets/` as WebP.
